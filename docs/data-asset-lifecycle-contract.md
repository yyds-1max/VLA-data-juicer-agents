# 数据资产生命周期契约

> 状态：本地与服务器实现已冻结（2026-08-11）
>
> 适用范围：导航数据；机械臂等后续领域复用相同边界，但不在本次实现范围内。

## 1. 目标

数据资产使用四条互不覆盖的状态轴：

```text
数据处理
自动标注
人工复核
训练发布
```

目录事实、标注执行、人工决策和训练准入不得再压缩为同一个状态。M2 的
AnnotationJob、TrajectoryReviewTask 和 CompatibilityPublication 状态机保持不变；
本契约只规定数据资产读模型以及新的日期级 DatasetRelease 事实。

## 2. 状态与作用范围

| 状态轴 | Segment | 外层 clip | 日期 |
| --- | --- | --- | --- |
| 数据处理 | 不展示 | 具体状态 | 按 clip 聚合 |
| 自动标注 | 具体状态 | 按 Segment 聚合 | 按 clip 聚合 |
| 人工复核 | 具体状态 | 按 Segment 聚合 | 按 clip 聚合 |
| 训练发布 | 不适用 | 不适用 | 具体状态 |

### 2.1 数据处理

```text
待处理 / 已拆解 / 已同步 / 异常
```

Clip 根据自己的 raw、tmp_dir、sync_data 和扫描错误投影。日期采用最低完整进度：

1. 任一 clip 异常：异常；
2. 全部 clips 已同步：已同步；
3. 所有 clips 至少已拆解：已拆解；
4. 其他情况：待处理。

不能因为某一个 clip 已同步就把整个日期显示为已同步。

### 2.2 自动标注

```text
尚未标注 / 待首帧标注 / 处理中 / 已标注 / 异常
```

- preparing、tracking、tracked 和 postprocessing 统一投影为“处理中”；
- 详细阶段只在 AnnotationJob 详情页展示；
- 全部内部工作单元完成后处理或经人工明确跳过后，投影为“已标注”；
- Tracking 或后处理失败且无法继续时投影为“异常”；
- 内部状态混合但仍在推进时投影为“处理中”，不提供自动标注“部分完成”；
- 数据尚未同步时显示 `—`。

### 2.3 人工复核

Segment 具体状态：

```text
待复核 / 修正中 / 已退回 / 已验证 / 已废弃
```

Clip 和日期可增加聚合状态：

```text
部分完成 / 复核完成
```

聚合规则：

- 所有单元状态相同：显示该具体状态；
- 已验证和已废弃混合、但全部为终态：复核完成；
- 终态和未完成状态混合：部分完成；
- 尚未形成复核单元时显示 `—`。

初始标注阶段经人工明确 skip 的 Segment 作为“已废弃”单元参与复核聚合，并保留
原因和审计记录。

### 2.4 训练发布

训练发布只属于日期：

```text
— / 待发布 / 已发布
```

“待发布”是派生状态。一个日期只有同时满足以下条件才进入待发布：

1. 当前数据目录中的所有 clips 均已同步；
2. 所有纳入管理的复核单元均为已验证或已废弃；
3. 至少存在一个已验证单元；
4. 所有已验证单元的 M2 训练兼容文件均已成功生成；
5. 当前日期尚无 DatasetRelease 记录。

全部单元均已废弃时不能发布。`5 个已验证 + 1 个已废弃` 属于“复核完成”并允许
进入待发布。

“已发布”必须由不可变的 DatasetRelease 记录支撑。当前版本不建设发布后的范围
变化、版本升级或重新发布；默认已发布日期不再变更。

发布动作只登记该日期允许被模型训练模块选择：

- 不默认选中；
- 不移动或复制业务数据；
- 不重新生成轨迹文件；
- 不自动启动模型训练；
- 不等同于 M2 生成 `_trajectory_fix_five.json` 的 CompatibilityPublication。

发布备注可选。

## 3. 权威事实

```text
数据处理      → 导航数据目录扫描与系统处理事件
自动标注      → AnnotationJob / AnnotationSegment
人工复核      → TrajectoryReviewTask / ReviewDecision
兼容产物就绪  → CompatibilityPublication
训练发布      → DatasetRelease
```

DatasetRelease 至少记录：随机公开 ref、日期、范围 manifest SHA-256、clips 数、采集
总时长、已验证/已废弃单元数、操作者、部署实例、发布时间和可选备注。记录不可修改、
不可删除。

## 4. 页面契约

数据管理内部使用 URL 化页面：

```text
/data           数据资产
/data/releases  训练发布
```

日期表格：

```text
日期 / clip 数 / 总时长 / 数据状态 / 标注状态 / 复核状态 / 训练发布 / 详情 / 操作
```

日期“详情”复用自动标注列表中的卡片式 Popover，展示 raw 消息、已拆解 clips、已同步
clips 和同步图像帧。

Clip 表格：

```text
clip / 时长 / tmp_dir / sync_data / 数据状态 / 标注状态 / 复核状态 / 详情 / 操作
```

Clip“详情”展示 topic 摘要、raw 消息和同步图像帧。数据管理操作列只提供“查看同步
图像”；标注任务和人工复核操作继续集中在自动标注板块。

训练发布页分为“待发布”和“已发布”。待发布行展示日期、clips、总时长、已验证/
已废弃单元和最近更新时间；已发布行增加发布时间、发布人和可选备注。点击详情使用
同类卡片展示审计摘要。

## 5. 刷新

DataPilot 管理的数据拆解、同步、标注和复核变化继续通过持久领域事件触发受影响
日期的局部重读。当前训练发布由本页 mutation 完成，成功后页面立即重读 summary
和 release 列表，不额外引入跨页面发布事件。显式“刷新”执行完整数据目录和生命
周期重读，不启动任何处理 Runtime。绕过系统直接运行外部脚本时仍依赖显式刷新
发现变化。
